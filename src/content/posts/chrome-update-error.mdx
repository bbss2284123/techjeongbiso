크롬 업데이트 오류는 Chrome 정보 화면에 업데이트 실패가 뜨거나 업데이트가 멈출 때 생깁니다. 먼저 Chrome을 다시 시작하고, 안 되면 재부팅과 보안 프로그램을 확인합니다.

## 첫째 단계. Chrome 정보 열기

  caption="더보기, 도움말, Chrome 정보 순서로 누릅니다."
  type="capture"
  badge={false}
/>

크롬 오른쪽 위의 더보기를 누릅니다. 도움말에 마우스를 올리면 오른쪽에 메뉴가 열립니다. Chrome 정보를 누릅니다.

주소창에 chrome://settings/help 를 입력해도 같은 화면이 열립니다. [Chrome 고객센터](https://support.google.com/chrome/answer/95414?hl=ko)도 이 경로를 안내합니다.

## 둘째 단계. 다시 시작 누르기

  id="about"

  caption="버전 번호 줄 아래에 다시 시작이 보이는지 확인합니다."
  type="capture"
  badge={false}
/>

Chrome 정보 화면을 열면 크롬이 업데이트가 있는지 확인합니다. 버전 번호 아래에 다시 시작이 보이면 누릅니다. 열려 있던 탭은 다시 열립니다. 시크릿 창은 다시 열리지 않습니다.

다시 시작이 보이지 않으면 이미 최신 버전입니다. 고객센터도 같은 기준으로 안내합니다. Windows는 Chrome 창과 탭을 모두 닫은 뒤 다시 실행해도 업데이트가 적용됩니다.

## 셋째 단계. 오류 문구와 번호 읽기

/>

업데이트 실패 옆의 오류 번호를 읽습니다. [고객센터](https://support.google.com/chrome/answer/111996?hl=ko)는 번호를 이렇게 나눕니다.

- 오류 3 또는 11. 업데이트 서버를 사용할 수 없습니다.
- 오류 4 또는 10. 업데이트 확인을 시작하지 못했습니다.
- 오류 7 또는 12. 다운로드하지 못했습니다.
- 관리자가 업데이트를 사용 중지했습니다. 회사나 학교 컴퓨터면 관리자에게 문의합니다.

번호와 상관없이 아래 넷째 단계부터 차례로 해 봅니다.

## 넷째 단계. 컴퓨터 재부팅

업데이트가 중간에 끝나지 않았을 수 있습니다. 컴퓨터를 재부팅합니다. 다시 켜진 뒤 첫째 단계처럼 Chrome 정보를 엽니다.

## 다섯째 단계. 보안 프로그램과 방화벽 확인

바이러스 백신, 방화벽, 자녀 보호 프로그램이 업데이트 연결을 막을 수 있습니다. 설정에서 tools.google.com 과 dl.google.com 이 막혀 있지 않은지 봅니다. 막혀 있으면 허용한 뒤 Chrome 정보를 다시 엽니다. 프로그램마다 메뉴 이름이 달라서, 막힌 주소 목록은 그 프로그램의 도움말에서 찾습니다.

## 여섯째 단계. 북마크를 내보낸 뒤 다시 설치

앞 단계로 안 되면 Chrome을 다시 설치합니다. 먼저 북마크를 저장해 둡니다.

주소창에 chrome://bookmarks 를 엽니다. 오른쪽 위 더보기를 누르고 북마크 내보내기를 누릅니다. 파일을 저장할 위치를 고릅니다.

그다음 컴퓨터에서 Chrome을 제거합니다. 컴퓨터가 시스템 요구사항에 맞는지 확인한 뒤 Chrome을 새로 내려받아 설치합니다. Windows에서 계속 오류가 나면 고객센터가 안내하는 독립형 설치 프로그램을 씁니다. 회사 컴퓨터면 관리자에게 맡깁니다.

## 그래도 안 되면

Chrome은 Windows 10 이상에서 쓸 수 있습니다. Windows 7, 8, 8.1에서는 업데이트를 받을 수 없습니다. 이 경우 최신 운영체제로 바꿔야 합니다.

호환 모드로 Chrome을 실행하도록 설정해 두었다면 끕니다. Chrome 아이콘에서 마우스 오른쪽 버튼, 속성, 호환성에서 호환 모드 체크를 해제합니다. 고객센터가 안내하는 방법입니다.

인증서 경고가 따로 뜨면 [연결이 비공개로 설정되어 있지 않습니다](/chrome-cert-error/)를 봅니다.

## 자주 묻는 질문

Linux는 크롬 안의 업데이트 단추가 아니라 패키지 관리자로 업데이트합니다.

Mac은 Chrome이 응용 프로그램 폴더에 설치되어 있어야 합니다. Chrome 정보 화면에서 모든 사용자의 Chrome 자동 업데이트를 누를 수 있습니다.

업데이트를 끄는 방법은 권장하지 않습니다. 고객센터는 보안 업데이트를 위해 자동 업데이트를 안내합니다.

회사나 학교 컴퓨터에서 관리자가 업데이트를 막아 두었으면 사용자가 바꿀 수 없습니다. 관리자에게 문의합니다.
