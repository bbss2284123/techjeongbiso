DNS_PROBE_FINISHED_NXDOMAIN이 뜨면 크롬이 입력한 주소의 서버 위치를 찾지 못한 상태입니다. 주소 철자부터 확인하고, 맞으면 크롬의 DNS 기록을 비웁니다.

## 첫째 단계. 오류 코드와 주소 철자 확인

  caption="오류 코드 줄을 읽고 새로고침을 눌러 봅니다."
  type="capture"
  badge={false}
/>

제목은 사이트에 연결할 수 없음이고, 그 아래 주소에 오타가 있는지 확인하라는 문장과 DNS_PROBE_FINISHED_NXDOMAIN이 보입니다. 주소창의 철자를 다시 봅니다. 점이나 글자가 빠진 경우가 많습니다.

철자가 맞으면 새로고침을 누릅니다. [Chrome 고객센터](https://support.google.com/chrome/answer/6098869?hl=ko)는 연결 오류가 나면 페이지를 다시 로드하고 다른 사이트도 열리는지 확인하라고 안내합니다.

## 둘째 단계. 다른 사이트도 안 되는지 확인

평소 여는 다른 사이트를 엽니다. 다른 사이트는 열리고 이 주소만 안 되면, 주소가 없어졌거나 사이트 쪽 문제일 수 있습니다. 잠시 뒤에 다시 열어 봅니다.

여러 사이트가 모두 같으면 인터넷 연결이나 DNS 설정을 의심합니다. 아래 단계를 이어서 합니다.

## 셋째 단계. 크롬 DNS 캐시 비우기

<Shot
  id="cache"
  src="/posts/dns-probe-nxdomain/chrome-net-internals-clear-host-cache.webp"
  alt="크롬 net-internals DNS 화면. Host resolver cache 옆의 Clear host cache 버튼이 보입니다."
  caption="Clear host cache를 눌러 크롬이 저장한 DNS 기록을 비웁니다."
  type="capture"

주소창에 chrome://net-internals/#dns 를 입력하고 Enter를 누릅니다. Host resolver cache 옆의 Clear host cache 버튼을 누릅니다. 눌러도 화면에 따로 알림은 뜨지 않습니다.

이제 원래 주소를 다시 엽니다. 이 방법은 방문 기록이나 로그인 정보를 지우지 않습니다.

## 넷째 단계. 보안 DNS 설정 확인

주소창에 chrome://settings/security 를 엽니다. 아래로 내려 고급 영역의 보안 DNS 사용 항목을 찾습니다. 이 항목을 켜 두었다면 잠시 끄고 같은 주소를 다시 열어 봅니다. 회사나 학교 컴퓨터는 관리자가 이 설정을 잠가 둘 수 있고, 그러면 스위치가 회색으로 보입니다.

## 다섯째 단계. 공유기 다시 시작

여러 사이트가 안 되면 모뎀과 공유기 전원을 끄고 잠시 기다린 뒤 다시 켭니다. 인터넷이 다시 연결되면 같은 주소를 엽니다. 카페나 공항 와이파이는 로그인 페이지를 먼저 통과해야 할 수 있습니다.

## 그래도 안 되면

다른 브라우저에서도 같은 주소가 안 열리면 크롬 문제가 아니라 주소나 사이트 쪽 문제입니다. 사이트 관리자에게 문의하거나 잠시 뒤에 다시 시도합니다.

크롬만 안 되면 [연결 및 로드 오류 안내](https://support.google.com/chrome/answer/6098869?hl=ko)의 순서대로 확장 프로그램을 모두 끈 뒤 하나씩 다시 켜 봅니다. 인증서 경고가 따로 뜨면 [연결이 비공개로 설정되어 있지 않습니다](/chrome-cert-error/)를 봅니다. 응답이 너무 오래 걸리면 [ERR_CONNECTION_TIMED_OUT 해결](/err-connection-timed-out/)을 봅니다.

## 자주 묻는 질문

휴대폰 크롬에도 같은 코드가 뜰 수 있습니다. 와이파이와 모바일 데이터를 바꿔 보고, 한쪽에서만 안 되면 그 네트워크를 의심합니다.

DNS_PROBE_FINISHED_NXDOMAIN은 입력한 주소를 찾지 못한 상태이고, ERR_CONNECTION_TIMED_OUT은 주소는 찾았지만 응답이 너무 늦은 상태입니다.

주소가 맞는데 한 사이트만 계속 안 되면 그 사이트가 닫혔거나 주소가 바뀐 경우일 수 있습니다.
