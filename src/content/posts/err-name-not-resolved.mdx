ERR_NAME_NOT_RESOLVED가 뜨면 크롬이 입력한 주소의 서버 IP를 찾지 못한 상태입니다. 주소 철자부터 확인하고, 맞으면 크롬의 DNS 기록을 비웁니다.

## 첫째 단계. 오류 코드와 주소 철자 확인

<Shot
  id="error"
  src="/posts/err-name-not-resolved/chrome-err-name-not-resolved-screen.webp"

  caption="오류 코드 줄과 주소창의 주소를 확인합니다."
  type="capture"
  badge={false}
/>

화면에 '서버 IP 주소를 찾을 수 없습니다'와 ERR_NAME_NOT_RESOLVED가 보이는지 확인합니다. 주소창의 주소도 봅니다. 점이나 글자가 빠졌으면 고쳐서 다시 엽니다.

철자가 맞으면 '새로고침'을 누릅니다. [Chrome 고객센터](https://support.google.com/chrome/answer/6098869?hl=ko)도 연결 오류가 나면 페이지를 다시 로드하고 다른 사이트가 열리는지 확인하라고 안내합니다.

## 둘째 단계. 크롬 DNS 캐시 비우기

<Shot
  id="cache"
  src="/posts/err-name-not-resolved/chrome-clear-host-cache.webp"
  alt="크롬 net-internals DNS 화면. 왼쪽 DNS 메뉴와 Clear host cache 버튼에 파란 번호 표시가 있습니다."
  caption="DNS 메뉴에서 Clear host cache를 누릅니다."
  type="capture"
  badge={false}
/>

주소창에 chrome://net-internals/#dns 를 입력하고 Enter를 누릅니다. 왼쪽 DNS 메뉴가 선택되어 있는지 봅니다. 'Clear host cache'를 누릅니다. 눌러도 따로 알림은 뜨지 않습니다.

이제 원래 주소를 다시 엽니다. 방문 기록이나 로그인 정보는 지워지지 않습니다.

## 셋째 단계. 프록시 설정 확인

<Shot
  id="proxy"

주소창에 chrome://settings/system 을 입력합니다. '컴퓨터 프록시 설정 열기'를 누릅니다. 컴퓨터의 프록시 설정 창이 열립니다. 쓰지 않는 프록시 서버가 켜져 있으면 끕니다. 회사나 학교 컴퓨터는 관리자가 정한 설정이므로 바꾸지 말고 관리자에게 문의합니다.

## 넷째 단계. 공유기 다시 시작

여러 사이트가 모두 안 되면 모뎀과 공유기 전원을 끄고 잠시 기다린 뒤 다시 켭니다. 인터넷이 다시 연결되면 같은 주소를 엽니다. 카페나 공항 와이파이는 로그인 페이지를 먼저 통과해야 할 수 있습니다.

## 그래도 안 되면

다른 브라우저에서도 같은 주소가 안 열리면 크롬 문제가 아니라 주소나 사이트 쪽 문제입니다. 잠시 뒤에 다시 시도하거나 사이트 관리자에게 문의합니다.

크롬에서만 안 되면 확장 프로그램을 모두 끈 뒤 하나씩 다시 켜 봅니다. 같은 뜻의 다른 화면은 [DNS_PROBE_FINISHED_NXDOMAIN 해결](/dns-probe-nxdomain/)을, 응답이 너무 늦으면 [ERR_CONNECTION_TIMED_OUT 해결](/err-connection-timed-out/)을 봅니다.

## 자주 묻는 질문

휴대폰 크롬에도 같은 코드가 뜰 수 있습니다. 와이파이와 모바일 데이터를 바꿔 보고, 한쪽에서만 안 되면 그 네트워크를 의심합니다.

ERR_NAME_NOT_RESOLVED와 DNS_PROBE_FINISHED_NXDOMAIN은 모두 주소를 찾지 못했다는 뜻입니다. 크롬이 원인을 추가로 확인한 결과에 따라 표시가 달라질 수 있습니다.

주소가 맞는데 한 사이트만 계속 안 되면 그 사이트가 닫혔거나 주소가 바뀐 경우일 수 있습니다.
